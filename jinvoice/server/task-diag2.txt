읽기·시험만 해 줘. 아무것도 바꾸지 마. 비밀값(쿠키 값, secret_key) 출력 금지.
1. D:/0.make/appsite/data/config.json 의 secret_key 로 '관리자' 이름 쿠키를 만들어:
   exp=int(time.time())+900; who=base64.urlsafe_b64encode('관리자'.encode()).decode(); sig=hmac.new(secret.encode(), b"jinvoice-user|"+f"{exp}.{who}".encode(), hashlib.sha256).hexdigest(); 값 = f"{exp}.{who}.{sig}"
2. 이 쿠키(jv_admin, 경로 /jinvoice)로 https://imist.co.kr/jinvoice/app/ 를 요청해서
   - 응답 헤더 Content-Security-Policy, Cache-Control 전체 (그대로 보여 줘)
   - HTML 안에 jv-user.js 가 있는지, 있으면 그 script 태그 한 줄
3. 파이썬 playwright 가 없으면 pip 로 D:/0.make/JinVoice-cache/pwtest 가상환경에 playwright 만 설치하고 `playwright install chromium` 대신 설치된 Edge(channel="msedge")를 써. 화면 1280x800 으로 쿠키를 넣고 https://imist.co.kr/jinvoice/app/ 를 열어 15초 기다린 뒤:
   - 콘솔 오류/경고 전부 (특히 CSP, jv-user, /jinvoice/me)
   - 네트워크에서 jv-user.js 와 /jinvoice/me 의 응답 코드
   - document.getElementById('jv-who') 가 있는지, 있으면 getBoundingClientRect 와 화면에 보이는지(elementFromPoint 로 그 위치 맨 위 요소가 jv-who 안인지)
   - 스크린샷을 D:/0.make/JinVoice-cache/web-shot.png 로 저장하고, 그 파일을 base64 로 출력하지 말고 크기만 보고.
4. 같은 것을 390x844 (모바일) 로도 한 번.
