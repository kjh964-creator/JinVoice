JinVoice(음성 엔진) 서버 설치 1단계를 해 줘. 승인 없이 진행하고, 비밀값은 출력하지 마. 기존 서비스(Caddy, appsite 5090, 웹하드, 채팅, Hermes 등)는 절대 멈추거나 바꾸지 마.

1. uv 설치: PowerShell에서 `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/0.12.13/install.ps1 | iex"` (사용자 설치). 설치 후 `uv --version` 확인. 이후 명령은 설치된 uv.exe 전체 경로로 실행.
2. 소스 받기: `git clone --depth 1 --branch v0.5.9 https://github.com/kjh964-creator/JinVoice.git D:\0.make\JinVoice` (이미 있으면 `git -C D:\0.make\JinVoice fetch --depth 1 origin tag v0.5.9` 후 `git -C D:\0.make\JinVoice checkout v0.5.9`). 서브모듈은 받지 않아도 됨.
3. 폴더 만들기: D:\0.make\JinVoiceData , D:\0.make\JinVoice-cache , D:\0.make\JinVoice-uv-cache
4. CPU용 실행 환경 설치 (오래 걸림, 몇 GB 다운로드): D:\0.make\JinVoice 에서 환경변수 UV_CACHE_DIR=D:\0.make\JinVoice-uv-cache 로
   `uv sync --frozen --no-dev --no-default-groups --group cpu`
   실패하면 오류 마지막 30줄을 보고. 성공하면 `uv run --no-sync python -c "import torch,sys;print(sys.version, torch.__version__, torch.cuda.is_available())"` 결과 보고.
5. 서버는 아직 실행하지 말 것.
6. 끝나고 D:\0.make\JinVoice 와 .venv 크기, D: 남은 용량, 현재 남은 RAM 을 보고.
